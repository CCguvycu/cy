# AI Glossary

Quick definitions — link to the full note for more detail.

| Term | Definition |
|------|-----------|
| **AGI** | Artificial General Intelligence — AI that matches or exceeds human ability across all cognitive tasks |
| **Agent** | An LLM that can take actions autonomously using tools and planning. See [[Concepts/Agents & Agentic AI]] |
| **Attention** | Mechanism that lets a model weigh the relevance of all tokens when processing each token. See [[Concepts/Transformer]] |
| **Backpropagation** | Algorithm for computing gradients and updating neural network weights during training |
| **Context window** | The maximum number of tokens a model can process at once |
| **Diffusion model** | Image generation approach: start with noise, gradually denoise guided by a prompt |
| **Embedding** | A numerical vector representing meaning. See [[Concepts/Embeddings]] |
| **Fine-tuning** | Further training a pre-trained model on a specific dataset. See [[Concepts/Training & Fine-tuning]] |
| **Foundation model** | A large model trained on broad data, used as a base for many tasks |
| **Hallucination** | When a model confidently states something false |
| **Inference** | Running a trained model to generate output (as opposed to training) |
| **LLM** | Large Language Model. See [[Concepts/Large Language Models]] |
| **LoRA** | Low-Rank Adaptation — efficient fine-tuning that only trains small adapter layers |
| **Multimodal** | A model that handles multiple types of data (text, image, audio). See [[Concepts/Multimodal AI]] |
| **Parameters** | The learnable numerical weights inside a neural network |
| **Perplexity** | A measure of how well a model predicts text — lower = better |
| **Prompt** | The input text given to a model |
| **RAG** | Retrieval-Augmented Generation. See [[Concepts/RAG]] |
| **RLHF** | Reinforcement Learning from Human Feedback — aligns models with human preference |
| **System prompt** | Instructions given to a model before the user's message, setting its behaviour |
| **Temperature** | Controls randomness in output. 0 = deterministic, higher = more creative |
| **Token** | The basic unit of text in an LLM. See [[Concepts/Tokens]] |
| **Transformer** | The neural network architecture behind all modern LLMs. See [[Concepts/Transformer]] |
| **Vector database** | Database optimised for storing and searching embeddings |
| **Zero-shot** | Asking a model to do something without any examples |
| **Few-shot** | Giving 2–5 examples in the prompt to guide the model's output |
