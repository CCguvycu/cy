## Models (2025)
| Model | Best for |
|-------|---------|
| Claude Opus 4 | Complex reasoning, long tasks |

| Claude Haiku 4 | Fast, lightweight tasks |

## Strengths
- Long context window (up to 200k tokens)
- Strong at coding, analysis, and writing
- Follows instructions carefully
- Built-in safety focus (Constitutional AI)

## Key features
- **Extended thinking** — shows reasoning steps
- **Tool use / function calling** — connect to APIs and code
- **Vision** — analyse images
- **Prompt caching** — reduce cost on repeated context

## Tips
- Be explicit and detailed in system prompts
- Use XML tags to structure complex prompts (`<context>`, `<instructions>`)
- Temperature 0 for deterministic/factual tasks
