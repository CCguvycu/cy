# Perplexity AI

**Made by:** Perplexity AI  
**Website:** https://perplexity.ai  
**Type:** AI-powered search engine

## What it does
Perplexity answers questions with cited sources — it searches the web in real time and synthesises the results into a concise answer with links.

## Why it's useful
- Every answer includes citations — easy to verify
- Real-time web access (unlike base LLMs)
- Follows up questions in a threaded conversation
- "Focus" modes to target specific sources

## Focus modes
| Mode | Searches |
|------|---------|
| All | General web |
| Academic | Scholarly papers |
| YouTube | Video content |
| Reddit | Community discussions |
| News | Recent news |

## Perplexity vs Google vs ChatGPT
| | Perplexity | Google | ChatGPT |
|--|------------|--------|---------|
| Cited sources | ✅ Always | ✅ Links | ❌ Sometimes |
| Real-time | ✅ | ✅ | ✅ (with browsing) |
| Synthesis | ✅ Strong | ❌ You read it | ✅ Strong |
| Best for | Research | Discovery | Conversation |

## Tips
- Use Academic mode for research papers
- Ask follow-up questions in the same thread
