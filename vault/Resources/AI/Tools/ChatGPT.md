# ChatGPT

**Made by:** OpenAI  
**Website:** https://chatgpt.com  
**API:** OpenAI API

## Models (2025)
| Model | Notes |
|-------|-------|
| GPT-4o | Multimodal flagship — text, image, audio |
| GPT-4o mini | Fast and cheap |
| o3 / o4-mini | Reasoning models (think before answering) |

## Strengths
- Huge ecosystem and plugin/GPT store
- Strong multimodal capabilities
- Wide integrations (Microsoft 365, etc.)
- Broad general knowledge

## Key features
- **GPTs** — custom assistants with instructions + tools
- **Code Interpreter** — runs Python in-session
- **Web browsing** — real-time search
- **Image generation** — DALL·E integration

## Tips
- Use custom GPTs to save system prompts for repeated tasks
- o3/o4-mini models are better for maths and logic
- Attach files for document analysis
