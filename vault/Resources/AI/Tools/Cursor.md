# Cursor

**Made by:** Anysphere  
**Website:** https://cursor.sh  
**Type:** AI-powered code editor (VS Code fork)

## What it does
Cursor is a code editor with deep AI integration — it can edit, explain, and write code across your entire codebase.

## Key features
| Feature | Shortcut | Description |
|---------|----------|-------------|
| Chat | `Ctrl+L` | Ask questions about your code |
| Composer | `Ctrl+I` | Multi-file AI edits |
| Inline edit | `Ctrl+K` | Edit selected code with a prompt |
| Tab autocomplete | `Tab` | AI-powered next-line prediction |

## Tips
- Use `@codebase` in chat to ask questions about the whole project
- Use `@docs` to pull in external documentation
- Add a `.cursorrules` file in the project root to set persistent instructions
- Composer is best for larger refactors spanning multiple files

## Models available
Cursor can use GPT-4o, Claude Sonnet/Opus, and others depending on your plan.
