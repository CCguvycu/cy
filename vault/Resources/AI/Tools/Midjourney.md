# Midjourney

**Made by:** Midjourney Inc.  
**Access:** Discord bot + web app (midjourney.com)

## What it does
Generates high-quality images from text prompts. Known for artistic, stylised output.

## Prompt structure
```
/imagine [subject], [style], [lighting], [camera], [mood] --ar 16:9 --v 6
```

## Useful parameters
| Parameter | Effect |
|-----------|--------|
| `--ar 16:9` | Aspect ratio |
| `--v 6` | Model version |
| `--style raw` | Less opinionated, closer to prompt |
| `--q 2` | Higher quality (slower) |
| `--no [x]` | Exclude element from image |
| `--seed [n]` | Reproducible results |

## Style keywords to know
- `photorealistic`, `cinematic lighting`, `shot on Sony A7`
- `digital art`, `concept art`, `oil painting`
- `isometric`, `flat design`, `low poly`
