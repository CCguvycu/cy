# GitHub Copilot

**Made by:** GitHub (Microsoft / OpenAI)  
**Website:** https://github.com/features/copilot  
**Type:** AI coding assistant — IDE extension

## What it does
Copilot autocompletes code inline as you type, and offers a chat interface for questions and edits across your codebase.

## Features
| Feature | Description |
|---------|-------------|
| Inline autocomplete | Suggests next line(s) as you type |
| Copilot Chat | Ask questions about your code |
| `/fix` | Explain and fix errors |
| `/explain` | Break down a block of code |
| `/tests` | Generate unit tests |
| `/doc` | Write docstrings |

## IDE support
- VS Code
- JetBrains (IntelliJ, PyCharm, etc.)
- Neovim
- Visual Studio

## Copilot vs Cursor
| | Copilot | Cursor |
|--|---------|--------|
| Editor | Plugin for existing editors | Standalone editor (VS Code fork) |
| Multi-file edits | Limited | Strong (Composer) |
| Model choice | GPT-4o / Claude | GPT-4o, Claude, others |
| Price | $10–19/mo | $20/mo |

## Tips
- Write a comment describing what you want before the function — Copilot will implement it
- Accept with `Tab`, reject with `Esc`, cycle suggestions with `Alt+]`
- Use Copilot Chat with `@workspace` to ask about the whole project
