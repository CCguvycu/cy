# Multimodal AI

Multimodal AI models can process and generate more than one type of data — text, images, audio, video, or code.

## Input modalities
| Modality | Examples |
|----------|---------|
| Text | Prompts, documents, code |
| Image | Photos, screenshots, diagrams |
| Audio | Speech, music |
| Video | Clips, screen recordings |

## Output modalities
| Modality | Models |
|----------|--------|
| Text | All LLMs |
| Image | DALL·E, Midjourney, Stable Diffusion, Imagen |
| Audio | ElevenLabs, Whisper (transcription), Suno |
| Code | GPT-4o, Claude, Copilot |

## Notable multimodal models
- **GPT-4o** — text + image in, text out; also voice
- **Claude 3.5+** — text + image in, text out
- **Gemini** — text + image + audio + video
- **LLaVA** — open-source vision-language model

## Use cases
- Analyse a screenshot and explain what's wrong
- Describe an image for accessibility
- Extract text from a photo (OCR-style)
- Generate an image from a detailed description
- Transcribe audio to text (Whisper)
