# Neural Networks

Neural networks are the foundation of modern AI — loosely inspired by the brain, they learn by adjusting millions of numerical weights.

## Basic structure
- **Input layer** — receives raw data
- **Hidden layers** — transform data through weighted connections
- **Output layer** — produces a prediction or generation

## Learning
1. Make a prediction
2. Compare to the correct answer (**loss function**)
3. Backpropagate the error
4. Adjust weights slightly (**gradient descent**)
5. Repeat millions of times

## Key architectures
| Architecture | Best for |
|---|---|
| CNN (Convolutional) | Images |
| RNN / LSTM | Sequences (older approach) |
| [[Transformer]] | Text, images, audio (modern standard) |
| Diffusion model | Image/audio generation |
