# Brainstorming Prompts

## Generate ideas
```
Generate 10 ideas for [goal/problem].
Be creative — include some obvious ideas and some unconventional ones.
For each, give a one-sentence explanation of the core appeal.
```

## Devil's advocate
```
I'm planning to [idea/decision]. 
Play devil's advocate — give me the strongest case against this.
Be direct, not polite.
```

## First principles
```
Break down [problem/topic] from first principles.
Start from the most basic assumptions and build up.
Challenge any assumptions that are usually taken for granted.
```

## SWOT analysis
```
Run a SWOT analysis on [idea/product/decision]:
- Strengths
- Weaknesses
- Opportunities
- Threats

Be specific, not generic.
```

## Ask better questions
```
I'm trying to solve [problem].
What are the 5 most important questions I should be asking?
For each, explain why that question matters.
```
