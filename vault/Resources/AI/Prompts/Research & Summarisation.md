# Research & Summarisation Prompts

## Summarise a paper / article
```
Summarise this paper in plain language:
1. What problem does it solve?
2. What is the key method or approach?
3. What are the main results?
4. What are the limitations?
5. Why does it matter?

[paste abstract or paper]
```

## Compare two things
```
Compare [A] and [B] across the following dimensions:
- [dimension 1]
- [dimension 2]
- [dimension 3]

Present as a table, then give a one-paragraph recommendation for when to use each.
```

## Research a topic
```
Give me a structured overview of [topic]. Include:
- What it is (2–3 sentences)
- Why it matters
- Key concepts or components
- Current state / recent developments
- Key people or organisations involved
- Further reading suggestions
```

## Extract key info from a document
```
From the following document, extract:
- Main argument or conclusion
- Key data points or statistics
- Any action items or recommendations
- Open questions or uncertainties

[paste document]
```
