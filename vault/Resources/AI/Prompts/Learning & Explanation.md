# Learning & Explanation Prompts

## Explain simply
```
Explain [concept] to me like I'm [a 10-year-old / a smart non-expert / a first-year student].
Use an analogy if it helps.
Keep it under 200 words.
```

## Teach me step by step
```
Teach me how to [skill/task] from scratch.
Assume I know [prerequisite knowledge] but nothing else.
Break it into steps and explain the "why" behind each one.
```

## Test my understanding
```
I've just learned about [topic]. 
Ask me 5 questions to test my understanding — ranging from basic to advanced.
After I answer, give me feedback on each one.
```

## Build a learning plan
```
Create a 4-week learning plan for [topic/skill].
I can dedicate [X hours] per week.
Include: what to study, resources (books, videos, projects), and milestones.
```

## Mental model
```
Give me a mental model for thinking about [concept].
What's the core insight that makes everything else make sense?
What's a good analogy?
What are the limits of the analogy?
```
