# Coding Prompts

## Explain code
```
Explain what this code does in plain English. 
Assume the reader knows programming basics but is unfamiliar with this codebase.

[paste code]
```

## Debug
```
This code is not working as expected. 
Expected behaviour: [describe]
Actual behaviour: [describe]
Error message: [paste if any]

Find the bug and explain the fix.

[paste code]
```

## Write a function
```
Write a [language] function that:
- Takes [inputs]
- Returns [output]
- Handles [edge cases]
- Include type hints and a short docstring.
```

## Write unit tests
```
Write unit tests for the following function using [pytest / Jest / etc].
Cover: happy path, edge cases, and error cases.

[paste function]
```

## Code review
```
Review this code for:
1. Bugs or logic errors
2. Performance issues
3. Security vulnerabilities
4. Readability and naming

Be specific — quote the line and explain the issue.

[paste code]
```

## Refactor
```
Refactor this code to be cleaner and more maintainable.
Do not change the behaviour.
Explain each change you made and why.

[paste code]
```
