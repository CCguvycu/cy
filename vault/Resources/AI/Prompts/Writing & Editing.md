# Writing & Editing Prompts

## Improve my writing
```
Edit the following text for clarity, conciseness, and flow. 
Keep my voice and don't change the meaning. 
Return only the revised text.

[paste text]
```

## Rewrite for a specific audience
```
Rewrite the following for [audience, e.g. "a 10-year-old" / "a senior engineer" / "a non-technical executive"].
Keep it under [word count] words.

[paste text]
```

## Write a first draft
```
Write a [type: blog post / email / LinkedIn post] about [topic].
Tone: [casual / professional / persuasive].
Length: ~[word count] words.
Key points to include:
- [point 1]
- [point 2]
```

## Summarise long content
```
Summarise the following in [3 bullet points / 1 paragraph / 100 words].
Focus on the key takeaways, not the structure.

[paste content]
```

## Make it shorter
```
Cut this by 50% without losing any key information.

[paste text]
```

## Proofread
```
Proofread the following. List each error with the correction and a one-line explanation.
Do not rewrite the whole text.

[paste text]
```
